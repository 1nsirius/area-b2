Мгновенная доставка

При отправке письма подключенный игрок сразу получает визуальный Sproto-пуш 505 (mail_new_mail_notify), и у него загорается значок почты.

Автоматическое начисление

Игрок может забрать золото и алмазы по кнопке «Получить» внутри почты клиента. Баланс обновится автоматически без перезахода в игру.
